# Rambo.nvim

Rambo adds editor-style movement, selection, and editing to Neovim's Insert and Select modes. The `nvim` package configures it with default options, and `scripts/setup-nvim.sh` installs it through Lazy.nvim.

Neovim uses the `unnamedplus` clipboard. Rambo can synchronize clipboard registers when the clipboard option is enabled.

See the [Neovim keybindings](keybindings/nvim.md) and the [Rambo documentation](https://github.com/colomb8/rambo.nvim) for its full feature list.
