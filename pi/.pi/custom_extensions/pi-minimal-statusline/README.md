# pi-minimal-statusline

Split ledger statusline for Pi 1.5.0+: identity above the editor, native usage
below it, and live extension statuses separated by a dim `│` on additional
rows. The default is two core rows; use `--statusline-lines` or `/statusline`
to select one, two, or three. `/statusline details` shows the full values.

Configuration, deployment, and validation are documented in the canonical
[Pi documentation](../../../../docs/pi.md#split-ledger-statusline).
